Synch - Asynch

Synch -> handle operations step by step (loops, classical functions, if-else) Asynch -> handle operations seperately (setTimeout, setInterval, fetch). Asynch is more readible than promise. promise could be useful for the cases Promise.all, Promise.race

Critical point: awaits can be useful if you need to obtain the result to avoid interruption. For instance, without api response, we cannot move forward

CallBack

functions that can be used for other functions as ARGUMENT can be used espacially for Asynch architects.
