📘 TechCareer JavaScript – Practical Purpose

This repository contains practical JavaScript exercises created during the TechCareer learning process.
The main goal of this project is to reinforce JavaScript fundamentals through hands-on examples and small independent applications.

Each example focuses on a specific JavaScript concept and is designed to be simple, clear, and easy to understand.

🚀 Project Purpose

Practice core JavaScript fundamentals

Improve problem-solving skills with small examples

Understand DOM manipulation

Learn how JavaScript interacts with HTML

Build a strong foundation for advanced JavaScript topics

📂 Project Structure

Each workX.html file represents a standalone example.

Each workX.js file contains the JavaScript logic for that example.

🧠 Topics Covered

Some of the main topics included in this repository:

Variables and data types

Conditional statements

Loops

Functions

Events

DOM selection and manipulation

Basic algorithms

User input handling

📌 Notes

This repository is suitable for:

Beginners learning JavaScript

Developers who want to practice fundamentals

Anyone preparing for frontend development
